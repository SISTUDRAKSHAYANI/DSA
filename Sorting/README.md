# Sorting

## 📌 Overview

Sorting is the process of arranging elements in a particular order, usually in ascending or descending order. It is an important concept in Data Structures and Algorithms (DSA) that helps improve the efficiency of searching and other operations.

This section contains my Java implementations of various sorting algorithms as part of my DSA preparation.

## 📚 Topics Covered

- **Bubble Sort** – Repeatedly compares adjacent elements and swaps them if they are in the wrong order.
- **Selection Sort** – Selects the smallest element from the unsorted portion and places it in the correct position.
- **Insertion Sort** – Builds the sorted portion of the array by inserting each element into its appropriate position.
- **Cyclic Sort** – Places elements in their correct positions when the array contains elements within a specified range.
- **Merge Sort** – Uses the divide-and-conquer technique to divide an array into smaller subarrays, sort them, and merge them into a sorted array.

## ⏱️ Time Complexity

| Algorithm | Best Case | Average Case | Worst Case |
|---|---|---|---|
| Bubble Sort | O(n) | O(n²) | O(n²) |
| Selection Sort | O(n²) | O(n²) | O(n²) |
| Insertion Sort | O(n) | O(n²) | O(n²) |
| Cyclic Sort | O(n) | O(n) | O(n) |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) |

*Note: Bubble Sort achieves O(n) best-case time with an optimized implementation. Cyclic Sort achieves O(n) time under its usual range-based assumptions. Merge Sort typically requires O(n) auxiliary space for arrays.*
