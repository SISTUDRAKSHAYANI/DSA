## 📝 Problem Solving Approach

For every problem, I try to follow these steps:

1. Understand the problem clearly
2. Identify the input and expected output
3. Try solving it on my own
4. Find the pattern
5. Think about a brute-force approach
6. Optimize the approach
7. Analyze **Time Complexity**
8. Analyze **Space Complexity**
9. Implement the solution
10. Add important observations to my notes
