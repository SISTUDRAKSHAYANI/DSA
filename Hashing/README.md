# Hashing

## 📌 Overview
Hashing is a technique used to store and retrieve information efficiently by mapping elements to specific indices or keys. It helps solve problems involving frequency counting, duplicate detection, and fast searching.

## 🧠 Key Concepts
- Hashing and hash functions
- Hash tables
- Frequency counting
- HashMap and HashSet in Java
- Collision handling
- Time complexity of hashing
- Using hashing to optimize brute-force solutions

## ⚙️ Common Operations
- Inserting elements
- Searching for elements
- Updating frequencies
- Checking for duplicates
- Finding elements with specific frequencies

## ⏱️ Time Complexity
| Operation | Average Case | Worst Case |
|---|---|---|
| Insertion | O(1) | O(n) |
| Search | O(1) | O(n) |
| Deletion | O(1) | O(n) |

*Note: These complexities generally apply to hash tables; actual performance depends on the implementation and collision handling.*

## 💻 Java Collections
- `HashMap` — Stores key-value pairs.
- `HashSet` — Stores unique elements.
- `getOrDefault()` — Retrieves a value or returns a default.
- `containsKey()` — Checks whether a key exists.
- `contains()` — Checks whether an element exists in a set.

## 🎯 Problem-Solving Approach
1. Identify whether the problem requires fast lookup or frequency counting.
2. Choose an appropriate data structure, such as `HashMap` or `HashSet`.
3. Store elements or their frequencies.
4. Use the stored information to solve the problem efficiently.
5. Analyze the time and space complexity.
